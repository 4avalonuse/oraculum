# Oraculum core

Esta camada contém o domínio do ORACULUM: mercado, variáveis, eventos, timelines, relações, Workspace, analytics, OAlgo e OBacktest.

Ela integra a fundação gráfica existente sem transformar o gráfico no centro do domínio.

A visualização serve à investigação; a investigação não deve ser limitada pela visualização.
